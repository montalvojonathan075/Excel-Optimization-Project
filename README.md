# Excel Optimization Project – Sensitivity & QA Pipeline

## Overview
This project demonstrates advanced Excel modeling with:
- 12,800+ formulas across multiple sheets
- 304 scenario variations
- Sensitivity testing and edge‑case QA validation
- Interactive dashboards for reporting

## Purpose
Designed to streamline data workflows and ensure accuracy across complex datasets.

## Features
- Automated calculations with error handling
- Scenario testing framework
- QA validation layer
- Documentation for reproducibility

## How to Use
Open the Excel workbook and supporting tables. Dashboards and formulas are pre‑built for scenario testing and validation.
